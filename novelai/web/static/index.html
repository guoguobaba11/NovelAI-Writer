欢迎使用 NovelAI Writer

长篇小说修改工作流

本工具帮你把握事件链、时间顺序、人物性格、逻辑、信息把控的一致性，并让 LLM 给出可执行的修改建议。

推荐 4 步流程：

  1. 导入 你已有的 MD 手稿
  2. 建库 标注主要人物的 MBTI + 关键里程碑
  3. 扫描 看全本有哪些问题
  4. 优化 让 AI 给出具体修改建议

第 1 步：导入手稿

把你的 .md 文件准备好，按"卷头 / 回头"格式：

# 第一卷 长安惊变
天宝十四年冬...

## 第一回 雨夜仵作
（正文...）

## 第二回 琴声旧约
（正文...）

# 第二卷 暗流涌动
## 第三回 虎嗅蔷薇
（正文...）

然后点顶部 导入 按钮，或在 CLI 里：

novel> import-md 我的初稿.md --title=《书名》

第 2 步：标注 MBTI

给主要 5-8 个人物设置 MBTI（16型人格）。这是后续所有人物维度分析的基础：

novel> set-mbti 沈青砚 INTJ
novel> set-mbti 林婉 INFJ
novel> set-mbti 李琰 ENTJ

完成后左侧"建库 → MBTI 标注"会显示已标注的人物。

第 3 步：跑全本扫描

左侧"扫描"区有 4 个扫描器：

  • 伏笔扫描：烂尾、超期、提前揭晓
  • 逻辑链扫描：死人复活、因果倒置、地点冲突、信息泄漏
  • 文风漂移：句长、独白、描写密度的章节间差异
  • 性格漂移：人物 MBTI 与实际表现的偏差

不需要 LLM，纯启发式，秒级出结果。

第 4 步：AI 给修改建议

左侧"优化"区，让 LLM 基于前面的扫描结果给具体可执行的修改建议：

  • 针对某个人物的 MBTI / 弧光优化
  • 针对某对人物的交会优化
  • 一键全局优化（扫描全本给综合建议）

每条建议带 priority（high/medium/low）+ 章节范围 + 修改示例。点 ✓ 即视为已应用。

注：需要配置 NOVELAI_API_KEY 在 .env 中。
